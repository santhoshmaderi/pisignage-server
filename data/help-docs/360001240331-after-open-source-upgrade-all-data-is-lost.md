# After open source upgrade, all data is lost

Source: https://help.pisignage.com/hc/en-us/articles/360001240331-After-open-source-upgrade-all-data-is-lost
Keywords: corruption

In the later releases the mongo db has been renamed to 

"pisignage-server-dev" from "pisignage-dev".

If you do not see any of your previous data, you could rename the db to "pisignage-dev" in config/dev/development.js file.
