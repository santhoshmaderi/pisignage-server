# Controlling TV on/off through rs232 port

Source: https://help.pisignage.com/hc/en-us/articles/360004774952-Controlling-TV-on-off-through-rs232-port
Keywords: python script

piSignage calls TVon.py and TVoff.py scripts whenever TV ON and TV OFF events happen. These scripts need to be in /home/pi directory of pi player.
