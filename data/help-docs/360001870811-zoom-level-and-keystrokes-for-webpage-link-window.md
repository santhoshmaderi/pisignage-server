# zoom level and keystrokes for webpage link window

Source: https://help.pisignage.com/hc/en-us/articles/360001870811-zoom-level-and-keystrokes-for-webpage-link-window

You can set the zoom level and send a series of keystrokes after 10 seconds of link launch for webpage (CORS) links. After entering the link details in Add link, goto details page for that asset.

The capital letters and special keys are sent as shift+b, shift+2 (for @ character). For keynames please refer to https://www.piathome.com/homepage/docs/robotjs-key-syntax.html 

Also, you could add delay between keys (for e.g. when a new page is loaded after certain key strokes) by adding <number>ms, for e.g. 2000ms will add 2 second delay.
