# Template & layout library (piSignage managed)

Source: https://pisignage.com/templates
Keywords: template, templates, template library, template marketplace, design, layout, custom layout, designer

Want ready-made, professionally designed layouts instead of building every screen from scratch? The **template library and designer** are part of **piSignage managed**.

What you get:
- **Template library** — a catalog of ready-to-use layouts for menus, notices, dashboards and more.
- **Visual template designer** — create multi-zone custom layouts and reuse them across playlists and groups.
- **Faster content creation** — start from a template and swap in your own media.

Good for teams that want polished screens quickly without design effort.
