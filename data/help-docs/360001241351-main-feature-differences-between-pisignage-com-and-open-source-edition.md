# Main feature differences between pisignage.com and open source edition

Source: https://help.pisignage.com/hc/en-us/articles/360001241351-Main-feature-differences-between-pisignage-com-and-open-source-edition
Keywords: white label

pisignage.com is a ready-to-go service for managing players. It  has full featured user management and report modules. The UI is different and multi-language support is available only in pisignage.com service.

We offer white-labelled server on an annual subscription fee which shares the same code base as pisignage.com.
