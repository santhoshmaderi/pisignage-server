# Raspberry Pi 3B+ support 

Source: https://help.pisignage.com/hc/en-us/articles/360002079252-Raspberry-Pi-3B-support
Keywords: rainbow screen

We have released new 1.9.9 image which supports new pi 3 B+ hardware, if you face any issues let us know at support@pisignage.com.

Also, note

-
Power Supply (PSU) - The new Raspberry Pi 3B+ needs more juice than previous models - You'll need an official 5.1V 2.5A power supply (or equivalent).
