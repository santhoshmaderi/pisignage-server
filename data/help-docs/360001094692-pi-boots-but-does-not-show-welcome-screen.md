# pi boots but does not show welcome screen

Source: https://help.pisignage.com/hc/en-us/articles/360001094692-pi-boots-but-does-not-show-welcome-screen

SD card may be full since older versions of software did not delete the unwanted files. You can do one of the following to correct the player.

- Reprogram the SD card and boot the player.

-
OR copen the terminal using ssh or connecting a USB keyboard (press ctrl+alt+T)

- delete all files in /home/pi/media directory

- reboot

- upgrade the software
