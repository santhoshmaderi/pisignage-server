# Secure communication (https) between player & server

Source: https://help.pisignage.com/hc/en-us/articles/360002951612-Secure-communication-https-between-player-server

For https communication between player and server, please change the server address in the player to https://pisignage.com.

You can change the server address as per  https://help.pisignage.com/hc/en-us/articles/360001152611-How-to-change-player-settings-for-network-and-server
