# API details

Source: https://help.pisignage.com/hc/en-us/articles/360001242011-API-details

piSignage server, open-source server and pi players support REST based api for controlling player and server functions. Swagger based documentation is available and you can experiment with the apis as well. Please visit http://piathome.com/apidocs for details.

 First you need to authenticate and get token. This token is valid for 4 hours and can be used across apis.
