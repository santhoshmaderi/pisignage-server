# Playlists and Layout Settings

Source: https://help.pisignage.com/hc/en-us/articles/360001379971-Playlists-and-Layout-Settings
Keywords: Playlist types, custom, zones, custom video window, audio, delete asset

Playlist is a collection assets which need to be played for certain durations. In addition a playlist can have different layouts with multiple assets being shown at the same time. 

Also a ticker can be shown at the bottom of the screen as explained in this help article.

Playlists can be set as of special types like advert, domination, event, audio as explained in this help article.

There are pre-defined layout types which can be selected for the playlist.  Upto 3 zones can be shown with different assets in the pre-defined layouts and upto 6 zones can be shown in custom layouts. The layouts can be divided into 3 groups.

- Landscape layouts - 1,2a,2b,2c,2d,3a,3b,3c,3d,4a,4b,4c,4d

- Portrait layouts - 2ap,2bp,2ap270,2bp270

- Custom layouts - custom, customp, customp270 (last 2 are portraits) More about custom layout available in the support article

 

 

You can define custom video sizes under Layout selection popup (in video window tabs). Under Group Settings, image and video stretch option can be selected to play in full screen or zone. Otherwise they will be shown at actual size.

 

 

 

When you select an asset, it is shown in the main zone. Main zone can be shown as full screen for any asset by selecting the option for the asset.

Depending on the layout, assets for side, bottom, zone4, zone5, zone6 can be selected. 

Specify side and bottom files only when you want to change, otherwise previous content will continue to be shown and there will be no reloading

Under Asset window, all assets available are shown. You can

- select the assets you need in the playlist using checkbox on the extreme right

- if the same asset is to be shown multiple times in the playlist, you can duplicate the asset using the copy icon on the extreme right below checkbox

- Duration for video is show automatically and for other default duration from installation settings is shown. You can adjust these durations as you need

- The order for the assets can be adjusted by dragging them up or down with the hand icon

- To show main asset in full screen select the checkbox on the second row left

- Video assets can be muted by selecting mute option

- Audio files or streams can be played in background by selecting the background option

Audio precedence is given in this order if they are available and unmuted

Main > Side > Bottom > Background Audio

For the zone size and other details refer to this support article and the layout guide.

Webpage links and Youtube links can be shown only in main zone.
