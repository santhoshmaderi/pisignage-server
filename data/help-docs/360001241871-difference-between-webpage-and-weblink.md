# Difference between webpage and weblink

Source: https://help.pisignage.com/hc/en-us/articles/360001241871-Difference-between-webpage-and-weblink
Keywords: zoom, login

Weblinks are loaded in the same window inside iframe. But some webpages will not load due to Cross Origin issues.

Such links can be loaded using webpage type which opens another browser window. Also you can specify zoom level and any key-sequences to be sent with this type.
