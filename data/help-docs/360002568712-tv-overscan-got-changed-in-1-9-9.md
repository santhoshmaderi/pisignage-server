# TV overscan got changed in 1.9.9

Source: https://help.pisignage.com/hc/en-us/articles/360002568712-TV-overscan-got-changed-in-1-9-9

Although by default overscan was disabled, the default values was programmed as 40 and 20. This was causing overscan values applied even if overscan was disabled. In 1.9.9, we have commented these values.

If you need overscan, please enable overscan and adjust the values.
