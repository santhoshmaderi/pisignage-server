# Loading piSignage app for Chrome and Chromecast

Source: https://help.pisignage.com/hc/en-us/articles/360001469991-Loading-piSignage-app-for-Chrome-and-Chromecast

Chrome app for piSignage can be downloaded from the Chrome Store link.

For Chromecast, the piSignage app will be automatically downloaded when you cast from pisignage.com/players screen using the cast icon on the right hand side of menu bar. If cast-icon is not shown, please make sure the browser is Chrome and you have the chromecast extension installed in Chrome.
