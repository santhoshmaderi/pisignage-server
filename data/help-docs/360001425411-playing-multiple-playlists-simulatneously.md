# Playing multiple playlists simulatneously

Source: https://help.pisignage.com/hc/en-us/articles/360001425411-Playing-multiple-playlists-simulatneously
Keywords: nested playlist

In multi-layout playlists, you can assign playlists to side and bottom zones. These playlists can be synchronously played with the main playlist or they can be played independently.

When you select the zone where you want to add an asset, a popup appears as shown in the screenshot. You can select the playlist tab to select a playlist and play. If you select the play independently option, the playlist will play independently in that zone till the next deploy happens.
