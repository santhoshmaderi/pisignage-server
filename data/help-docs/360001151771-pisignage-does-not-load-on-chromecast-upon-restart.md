# piSignage does not load on Chromecast upon restart

Source: https://help.pisignage.com/hc/en-us/articles/360001151771-piSignage-does-not-load-on-Chromecast-upon-restart

Chromecast does not load apps unless "cast"ed from a device on the same network.

To restart piSignage, upon boot

- Use a Chrome Browser either in PC or smartphone from the same network

- Login at pisignage.com/login

-
In the top menu bar at the right hand side you will see a Chromecast icon (install Chromecast extension if you do not see chromecast icon)

- Click the icon and select start casting

- piSignage software will be downloaded and a ID will appear on the TV

- Register the ID at pisignage.com/players if not done already
