# Debian Trixie: Post-Install Setup Guide

Source: https://help.pisignage.com/hc/en-us/articles/56191130603673-Debian-Trixie-Post-Install-Setup-Guide

Install the Gnome Shell Extension Manager

sudo apt install gnome-shell-extension-manager

Open Extension Manager

 

From the Apps menu, open the Extension Manager application.

     

Browse for "Just Perfection" and Install

 

 

Configure "Just Perfection" Preferences

 

-

Click the gear icon to open the preferences.

-

Under the "Visibility" section, toggle the "Panel" option off.

-

Under "Behaviour", change the "Startup status" from "Overview" to "Desktop".

 

Restart the Linux Machine 

sudo reboot
