# Individual Player settings available in server UI

Source: https://help.pisignage.com/hc/en-us/articles/360001233351-Individual-Player-settings-available-in-server-UI
Keywords: Player setting, Location

Players are assigned to a group and Group settings are applied to all players in that Group. 

In addition to that there are certain settings which are available to per player under Players Tab and they are listed here.

1. Player group (select none to control player individually)

2. Timezone - Timezone is needed for playlist scheduling to work. Set the correct timezone for every player

3. Player name (click to edit)

4. Player Location - Location is IP address based and not always available. You can program your own location by clicking the location field of player.
