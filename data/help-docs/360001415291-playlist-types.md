# Playlist types

Source: https://help.pisignage.com/hc/en-us/articles/360001415291-Playlist-types
Keywords: domination, advt, event, audio

Apart from Regular playlists, there are special playlists which you set under playlist settings popup.

Advertisement Playlist - Advertisement playlists contain items that needs to be inserted between regular playlists items at regular intervals. The content can be played in all zones or only in the non-main zones. 

If an advert playlist is due to be inserted, it is done so after the current asset is played. In case of videos you can pause the video after a certain time and insert the advert. Refer to Group Settings on how to pause video after a time interval to check for adverts.

When the advert is due, you can play 1 or more assets of the advert playlist continuously. 

Domination Playlist - Domination playlist is like advert playlist, but scheduled at the start of a minute and played once. The duration can be programmed in multiples of minutes.

Audio Playlist - In addition to the signage content played out on HDMI interface, audio can be played on the 3.5mm aux port simultaneously. Only mp3/aac files are supported and audio playlist can be played in random order as well.

You can use this feature to play lounge music in the shop.

Event Playlist - Event playlist is played when an event occurs for a certain duration or until the next event occurs. The event is indicated to piSignage program by sending a Linux SIGUSR2 event.

In addition, there is a TV_OFF playlist available under Group for scheduling which turns off the TV when scheduled.
