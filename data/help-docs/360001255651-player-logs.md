# Player logs

Source: https://help.pisignage.com/hc/en-us/articles/360001255651-Player-logs
Keywords: debug

/home/pi/forever_out.log stores the log information for the pi player. This can be used to obtain valuable information regarding the player and its behaviour.

By going through the last 200 lines using the command 'tail -200 /home/pi/forever_out.log' information about connectivity, content not playing, crashes can be found.

In addition /home/pi/forever_err.log and /home/pi/forever.log store any starting issues with node server, upgrades and system level issues.

For issuing shell command "tail -200 /home/pi/forever_out.log" please go through the article https://help.pisignage.com/hc/en-us/articles/360001095632-Issue-shell-commands-or-connect-to-pi-terminal-

While raising a player related support issue, please send the output text of  "tail -200 /home/pi/forever_out.log" along with. This will help us analyse things faster.
