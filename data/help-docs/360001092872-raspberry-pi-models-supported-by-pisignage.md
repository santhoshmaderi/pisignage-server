# Raspberry Pi models supported by piSignage

Source: https://help.pisignage.com/hc/en-us/articles/360001092872-Raspberry-Pi-models-supported-by-piSignage
Keywords: pi 3, pi zero

piSignage runs on all models of Pi

Our intention is to support all versions of Pi (model B) as and when available. Currently piSignage runs on the following models as follows (Nov 2023)

- Pi Zero, Pi Zero W, Pi 1B, CM1 - Version 2.9.7 only

- Pi 2B, Pi 3B,CM3,Pi Zero 2W - Version 3.2.x only

- Pi 4B,CM4, Pi 400 - Version 3.2.x or 5.1.x-legacy or 5.1.x 

- Pi 5 - Version 5.1.0 onwards
