# Language support

Source: https://help.pisignage.com/hc/en-us/articles/360001413011-Language-support

There is support available for few languages and you could change the language of server UI by selecting the dropdown as shown in the screenshot.

We welcome you  to support a new language or enhance support for existing language. You can take the language template file available at https://github.com/colloqi/piSignage/blob/master/translation-files/template.pot and add the translation. We will add it to the server UI in the next release.
