# Access assets and media files in Pi

Source: https://help.pisignage.com/hc/en-us/articles/360001117251-Access-assets-and-media-files-in-Pi
Keywords: Raspbian

Pi Player is based on Raspbian OS which is a Linux variant.

You can ssh to the player IP address and the assets are stored in /home/pi/media directory.

or connect via browser http://[player ip]:8000/assets (use EDIT button to delete the assets)
