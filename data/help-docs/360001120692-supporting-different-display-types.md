# Supporting different display types

Source: https://help.pisignage.com/hc/en-us/articles/360001120692-Supporting-different-display-types
Keywords: LED

This can be done by changing the hdmi_group and hdmi_mode parameters in /boot/config.txt. For more details Raspberry Pi documentation.

You can edit the config.txt file as follows.

1. Connect to Pi terminal as described in artcicle

2. Use one of the editors to modify the content like nano or vi

- nano /boot/config/txt

3. Reboot the player
