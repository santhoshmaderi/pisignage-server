# Hardware needed for the piSignage player

Source: https://help.pisignage.com/hc/en-us/articles/360001093112-Hardware-needed-for-the-piSignage-player
Keywords: corruption, Lightning, bolt

Raspberry Pi player needs the following components

- Raspberry Pi board (Pi 3 Model B and Pi 4 are recommended)

- Class A1 SD card from a reputed vendor (minimum 8GB)

- Good quality USB power supply with 5V, 2.1A rating (many TVs do not supply enough current for Pi players, you will see a lightning icon if power is not enough)

- Enclosure for the Pi board

- HDMI and Ethernet cables

Many vendors like Amazon offer a kit that includes all these items and comes with a 1-year warranty.
