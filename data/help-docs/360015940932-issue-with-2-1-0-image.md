# Issue with 2.1.0 image 

Source: https://help.pisignage.com/hc/en-us/articles/360015940932-Issue-with-2-1-0-image
Keywords: SD card corruption, reboot, blank screen

The original 2.1.0 (not the modified image) had issues in terms of

- player restart not working, shows SD card terminal messages

- the screen is blank upon boot and takes 3-5 minutes for the content to show up.

 

To resolve the issue,

- Please reprogram the SD card image with 1.9.9aa or 2.1.0 modified image. 

- OR You could also fix the image by logging into the player and issuing the following commands

sudo apt-get -y --fix-missing update
sudo apt-get -y upgrade
sudo rpi-update
