# Reasons for player reboot

Source: https://help.pisignage.com/hc/en-us/articles/360001395672-Reasons-for-player-reboot

Player may reboot for the following of reasons when settings change

- After the SD card insertion and power-on, player will reboot first time to resize the disk partition to match your SD card size

- Whenever a  resolution, orientation, network configuration or overscan player will reboot for the settings to take effect

- After the software update

- After a setting is changed if the server is setting is different, player will change the setting to match that of server and reboots
