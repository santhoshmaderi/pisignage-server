# Delete or rename an Asset, Playlist or Group

Source: https://help.pisignage.com/hc/en-us/articles/360001225612-Delete-or-rename-an-Asset-Playlist-or-Group
Keywords: delete playlist, delete asset, delete group

Under Assets, Playlists and Groups screens, there is an EDIT button on the menu bar. By pressing edit button, you can delete or rename the item.

P.S. After renaming make sure to change the same in playlists, groups and player settings if needed.
