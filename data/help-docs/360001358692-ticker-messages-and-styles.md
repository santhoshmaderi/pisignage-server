# Ticker messages and styles

Source: https://help.pisignage.com/hc/en-us/articles/360001358692-Ticker-messages-and-styles
Keywords: RSS

You can add a Ticker message to appear at the bottom of the screen at the Group level or at Playlist level. If a playlist has a ticker that will have higher priority than group ticker.

Ticker can show a list of text messages that is entered in the Ticker Popup or you can display messages from a RSS source. 

The Ticker can be a scrolling text (right to left or left to right) or sliding from the bottom. CSS style can be applied to the Ticker as well the speed of the ticker can be specified as shown in the screenshot.
