# Player settings are restored back to old value upon reboot

Source: https://help.pisignage.com/hc/en-us/articles/360001233771-Player-settings-are-restored-back-to-old-value-upon-reboot

Server settings override the local piSignage player settings. So when pi connected to server it gets server settings which are different from the local settings and configures accordingly. Change the display settings under server group settings instead of player webUI when connected to server.
