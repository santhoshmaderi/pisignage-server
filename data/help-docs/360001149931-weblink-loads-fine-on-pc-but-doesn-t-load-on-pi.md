# Weblink loads fine on PC but doesn't load on Pi

Source: https://help.pisignage.com/hc/en-us/articles/360001149931-Weblink-loads-fine-on-PC-but-doesn-t-load-on-Pi

Raspberry Pi processor has limited processing capabilities compared to PC and hence when there is heavy JavaScript processing in the page it can not work properly.

Similarly flash content is not supported on Pi.

Videos are handled by GPU and hence able to play HD content.

Please try our Chrome App or Progressive web app at https://pisignage.com/getplayer  which you can use in PC platforms.
