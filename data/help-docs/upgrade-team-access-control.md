# Team & access control (piSignage managed)

Source: https://help.pisignage.com/hc/en-us/articles/360001413451-Adding-collaborators-other-users-to-manage-your-account
Keywords: user management, collaborators, multiple users, multi-user, roles, permissions, access control, sso, saml, single sign-on, teams

The open-source server is single-account. If you need several people managing screens, or enterprise sign-in, that lives in **piSignage managed**.

What you get:
- **Collaborators / multiple users** — invite teammates and give each one scoped access to only the groups, playlists and assets they should manage.
- **Role-based permissions** — control who can deploy, edit content, or only view.
- **SSO / SAML** — sign in with Microsoft Entra ID (Azure AD) and other identity providers, so access follows your corporate directory.

Great for teams, multi-location rollouts, agencies and franchises where more than one person touches the screens.

SAML SSO setup guide: https://help.pisignage.com/hc/en-us/articles/40667663637145-Setting-Up-SAML-SSO-for-piSignage-with-Microsoft-Entra-ID
