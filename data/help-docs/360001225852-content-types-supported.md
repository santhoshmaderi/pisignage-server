# Content types supported

Source: https://help.pisignage.com/hc/en-us/articles/360001225852-Content-types-supported
Keywords: supported files

piSignage Player supports

-
Pi natively supports mp4/h.264 video. If you are using pisignage.com or piSignage server you can upload the popular formats of videos (mp4| mov| m4v| avi| webm| wmv| flv| mkv| mpg| mpeg| 3gp) and they are converted to h264/mp4 format

- Audio mp3 or AAC format

- Streaming - YouTube, RTMP, RTSP(IP camera), Audio, Shoutcast and other popular streaming formats (which are supported by omxplayer, youtube-dl or livestreamer programs). Also refer to this blog article

- All types of image files - PNG, JPEG, GIF, BMP 

- html5 page with .html extension or zip file containing HTML assets  and index.html in root directory

- web links to show html static/dynamic pages (Heavy JavaScript pages may be sluggish due to CPU performance limitations). Add Cross Origin links as webpage links which support zoom and sending key-sequences as well.

- PDF

- Text message 

- Media RSS

- Custom Layouts - To show information like weather, clock, background image/video, multi zones upto 6, real time display
