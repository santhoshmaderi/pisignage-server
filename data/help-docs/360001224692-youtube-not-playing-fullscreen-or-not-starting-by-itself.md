# Youtube not playing fullscreen or not starting by itself

Source: https://help.pisignage.com/hc/en-us/articles/360001224692-Youtube-not-playing-fullscreen-or-not-starting-by-itself
Keywords: Chrome

Chrome piSignage app adds timestamp as query parameter to reload the url every cycle, this will interfere with other query parameters like YouTube autoplay, disable urlReload option under Group settings in such cases.
