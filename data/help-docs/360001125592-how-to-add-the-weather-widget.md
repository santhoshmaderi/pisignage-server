# How to add the weather widget 

Source: https://help.pisignage.com/hc/en-us/articles/360001125592-How-to-add-the-weather-widget

1. Take the example at https://github.com/colloqi/piSignage/tree/master/examples/weather (weather.html or one of the other files)

2. Change the city at line 160

3. Upload the file using Add Asset button under Assets Tab.

4. You can add the weather file to the playlist to play the file.
