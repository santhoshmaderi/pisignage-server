# Other players supported (non Raspberry Pi)

Keywords: android, pwa, chromecast, debian, ubuntu, nuc, players

Besides the standard Raspberry Pi player, piSignage offers:
1. Progressive Web App (PWA): needs a Chromium browser with HD video support. Install from https://pisignage.com/player2/
2. Debian/Ubuntu player: build the image per https://pisignage.com/releases/Player2_installation_procedure.html (works on Pi running Ubuntu, Intel NUC, Radxa Rock 4C+, Odroid N2).
3. Android app (Android TV and mobile): https://play.google.com/store/apps/details?id=com.pisignage.player2 - also works on newer Chromecast with Android TV.
