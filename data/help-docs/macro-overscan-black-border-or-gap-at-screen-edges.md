# Overscan - black border or gap at screen edges

Keywords: overscan, black border, gap, edges, display, cropped

A black border or gap at the edges of the display is usually caused by overscan. Adjust the overscan values from the player web UI at http://<player_ip>:8000/settings. Reduce the overscan values to shrink the border (or increase them to pull content inward). The player reboots to apply. More about overscan: https://en.wikipedia.org/wiki/Overscan
