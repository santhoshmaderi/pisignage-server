# Player is not reporting and not shown in server

Source: https://help.pisignage.com/hc/en-us/articles/360001255791-Player-is-not-reporting-and-not-shown-in-server

Change the server settings of the player to your server address and add port number 3000 at the end.

To do so either,

- connect keyboard to the player & press ctrl-N

- or connect through browser to the player http://<player ip address>:8000/settings.

Sometimes port 3000 is disabled by the windows firewall. Enable/open port 3000.
