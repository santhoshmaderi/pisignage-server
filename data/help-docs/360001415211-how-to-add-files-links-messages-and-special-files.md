# How to add files, links, messages and special files 

Source: https://help.pisignage.com/hc/en-us/articles/360001415211-How-to-add-files-links-messages-and-special-files
Keywords: validity, add asset

piSignage supports number of asset types which can be displayed on the screen, for details refer to content types and types of links.

All the assets be it files, templates, brand videos, special files, links, messages, notices and calendars are added in Assets Tab using Add button as shown in the screenshot.

 

When an file is added it is processed by the server for needed conversions, template processing, thumbnail creations and details extraction which may take upto few minutes. Once the processing is complete, the file type, details and category details are written to the data base. These details are displayed in asset and playlist screens. The details include resolution, duration of the video, file size, thumbnail and other details. 

Similarly when a link is added the details are captured and added to the database. Some details like zoom level, keystrokes to be sent in case of webpage link are added only in the asset details screen.

In the assets screen, you can add asset validity period. The players check the asset validity and play only if the asset is valid on that date. It is useful to show assets and adverts which are valid during a specific period (for e.g. Christmas time).

The assets can be renamed or deleted by using the "EDIT" button next to Add button. 

By clicking on the asset name, asset details screen is shown wherein you can view the asset or edit the details.
