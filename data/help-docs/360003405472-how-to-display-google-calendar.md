# How to display Google Calendar

Source: https://help.pisignage.com/hc/en-us/articles/360003405472-How-to-display-Google-Calendar

As mentioned in the Google help article get the embed code and add the iframe src link to the "Add link (weblink)" under Assets. Make sure you add only the iframe src attribute and not the entire code. Do not use customize option, instead add &mode=WEEK or &mode=AGENDA to display week calendar or only events.

We have removed earlier feature of adding Google Calendar type of asset under add assets
